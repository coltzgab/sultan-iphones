# Sultan iPhones

Projeto migrado de um HTML unico para React + Vite + TypeScript.

## Estrutura

- `src/components/`: interface principal da loja
- `src/data/`: catalogo tipado de iPhones e acessorios
- `src/types/`: tipos compartilhados
- `public/logo-sultan.jpeg`: logo da marca

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Objetivo desta base

- estabilizar o hero e o layout principal
- evitar quebrar textos por encoding
- facilitar crescimento com modal, carrinho e novas secoes
- deixar a pasta pronta para versionar no GitHub
